# 夜航练习室

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本机地址。麦克风需要本机地址或 HTTPS。

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8029>。可以通过 `NIGHT_SESSION_PORT` 指定其他端口。

## 换气回看

录完一遍后，工作台下方会按参考旋律留下的空档逐段给出判定：可听吸气、拖音、基本安静、证据不足、未录到。底噪基准取自当遍空档两侧最近的无声片段，风扇中途提速、麦克风无输入、只录了半句都会如实标注能比较到哪里；噪声与气声叠在一起的分不出来时，会列进"无法归类"，每个空档旁都有空档 / 前后基准 / 接界位置的复听按钮。

## 验证换气分析

```sh
node scripts/validate-breath.mjs
```

用合成音频验证七组场景：风扇在空档中提速、一段无输入、只录到半句、换气紧邻起音、拖音、气声与风扇同能量，以及真实歌曲第一句。
